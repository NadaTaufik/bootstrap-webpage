## Meeting 8 — JavaScript ES6+

Focused on JavaScript fundamentals and data processing.

- Variables, objects, template literals, and destructuring.
- Pure functions and arrow functions.
- Array methods: `map()`, `filter()`, `find()`, and `sort()`.
- Spread operator, optional chaining, and nullish coalescing.
- Dynamic skill cards and learning goals generated from JavaScript data.

## Meeting 9 — DOM, Events, and Interactivity

Extended the previous webpage with interactive features.

- DOM selection using `querySelector()` and `querySelectorAll()`.
- Dynamic project cards using `createElement()`, `textContent`, and `append()`.
- Category filtering with one parent event listener.
- Active button states and empty-list handling.
- Form validation with field-specific errors, `aria-invalid`, and `preventDefault()`.
- Testing and debugging using Firefox Developer Tools.
